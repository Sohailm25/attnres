# Gaps Synthesis

The local thesis review identified seven non-negotiable gaps that had to be closed before the scaffold was usable:

1. Oracle-alpha needed to be framed honestly relative to co-adaptation.
2. Tool-breakage needed to become a required experiment lane.
3. Router query geometry needed to stand in for the missing `w_l` analysis.
4. Block structure needed an explicit `8 clusters` test.
5. Softmax needed to be compared directly with unconstrained and top-k routing.
6. Figure 8 had to become a preregistered prediction surface.
7. Safety needed a refusal or honesty-focused routing lane.

Those thesis-level changes are now encoded in the repo structure and control documents.

The deeper methodology audit added five implementation-level hazards that must also stay visible:

1. Ward linkage cannot be used directly with Jensen-Shannon distances.
2. Uniform-routing reconstruction should match the original logits after final normalization, not `logits / L`.
3. Exact per-source routed-logit decomposition requires the shared final normalization factor from the full routed mixture.
4. Claim-bearing significance tests need a sequence-level unit or an explicit dependence-aware alternative.
5. `resid_post`-only caching is insufficient for final Figure 8 and layer-type-specialization claims.

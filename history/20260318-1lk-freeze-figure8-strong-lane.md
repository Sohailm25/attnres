# ABOUTME: Records the strategic Figure 8 decision after the primary-model oracle lane became stronger.
# ABOUTME: Freezes the strong Figure 8 / trained-routing lane on the current proxy rather than reopening it without a materially more faithful path.

## Question

After the primary-model Gemma oracle lane cleared held-out predictiveness,
pattern analysis, and the prereg regime comparison, should the repo reopen the
strong Figure 8 / trained-routing alignment lane now, or keep it frozen on the
current local proxy?

## Decision

Keep the strong Figure 8 / trained-routing lane **frozen** at the current
descriptive boundary.

Do **not** start another local Figure 8 build on the current proxy family, and
do **not** open a new strong-claim Figure 8 implementation issue right now.

The current local proxy remains valid for:

- descriptive comparison against the published Figure 8 pattern surface
- bounded discussion of what the local small trained-routing reproduction does
  and does not recover

It does **not** currently justify:

- strong language that the local proxy independently recovers the published
  AttnRes Figure 8 signatures
- a new round of “more faithful” work unless the repo first has a concrete
  materially more faithful path in hand

## Why Freeze Is The Honest Choice

1. The repo has already exhausted the faithful local rescue path on the current
   proxy family.
   Tokenization, width, horizon, corpus, best-checkpoint export, and matched
   regularization have all been tried. The result stayed operationally real but
   scientifically mixed.

2. The current reopen conditions are still abstract, not executable.
   `resattn-9fo` already established the only honest reopen conditions:
   - a larger or otherwise more faithful local AttnRes reproduction
   - another open depth-mixing comparison with released weights, fallback-only
   - new external evidence for a paper-faithful objective change
   None of those is currently an implemented repo path ready for immediate
   execution.

3. The repo has stronger paper-shaping work elsewhere now.
   The primary-model Gemma oracle lane is no longer a weak feasibility story.
   The safety lane also has a live bounded extension path. Reopening Figure 8
   now would be a speculative new build, not the clearest next risk reduction.

4. A vague promise to revisit later is weaker than an explicit freeze.
   The honest state is not “Figure 8 is next when we get around to it.” The
   honest state is “the strong Figure 8 lane is frozen until a concretely more
   faithful path exists.”

## Consequence

- Close `resattn-1lk`.
- Keep the current Figure 8 artifacts as descriptive-only for the strong-claim
  boundary.
- Move repo priority to the next active non-frozen lanes rather than continuing
  proxy iteration by inertia.

## Reopen Condition

Only reopen the strong Figure 8 lane if one of these becomes concrete enough to
execute immediately:

- a materially larger or otherwise more faithful local AttnRes reproduction
  with a specific runnable plan
- a released open depth-mixing comparison that is close enough to serve as the
  logged fallback proxy
- new external evidence that a specific training ingredient missing locally is
  part of the real AttnRes recipe and is worth implementing faithfully
